
Веб-приложение магазина одежды. Работает на SQLite (по умолчанию, ничего ставить не нужно)
или на MySQL (через `config.ini`).

## Запуск
```bash
pip install -r requirements.txt
python app.py
```
Откройте http://127.0.0.1:5000. На Windows можно просто запустить `Запуск.bat`.

Демо-вход: `admin / admin123` (администратор), `user / user123` (покупатель).
**Перед публикацией в интернете смените пароль администратора.**

## Возможности
- Вход, регистрация, выход (пароли — PBKDF2 с солью; ограничение числа неудачных попыток входа)
- Каталог карточками с фото; поиск без учёта регистра, фильтры (категория, размер, цена, «в наличии»), живое обновление без перезагрузки
- Страница товара, корзина (+/−/удалить), оформление заказа со списанием остатков одной транзакцией
- Администратор: добавление товара с фото, смена фото, удаление
- Оформление: 10 готовых цветов + свой цвет + тёмная тема (сохраняется для каждого пользователя)

## MySQL
Скопируйте `config.example.ini` в `config.ini`, поставьте `backend = mysql` и впишите данные сервера.
Таблицы и демо-данные создаются автоматически.
