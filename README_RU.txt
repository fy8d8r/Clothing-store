STYLE STORE — инструкция запуска

1. Установите Python 3.10 или новее.
2. Откройте папку проекта в терминале.
3. Установите зависимости:
   python -m pip install -r requirements.txt
4. Запустите приложение:
   python main.py

Демо-вход:
  Администратор: admin / admin123
  Покупатель:    user / user123

Что добавлено:
- Каталог карточками с фотографиями вместо таблицы.
- Загрузка изображения при добавлении товара администратором.
- Копирование изображений в product_images, поэтому исходный файл можно переместить.
- Корзина с изменением количества и удалением позиций.
- Оформление заказа с уменьшением остатков на складе.
- Автоматическая миграция старой базы данных: существующие товары и пользователи сохраняются.

Важно:
- Корзина хранится в памяти до закрытия программы.
- Заказ пока оформляется локально, без онлайн-оплаты и доставки.
- Смените демо-пароль администратора перед реальным использованием.
